# 企画前提（実装者向けの基準）

作成日：2026年10月24日　対象：『きみのための甲子園』の初回実装

この文書は、実装者が判断に迷ったときの基準です。**ゲームの画面や本文に、この文書の説明を挿入しないでください。** 旧い草案と違う場合は、この文書の整理を優先します。

## 作品全体の基準

- 表面は爽やかな高校野球の青春。選手の努力と実力は本物だが、美空への恋心と男子高校生らしい欲が優勝への熱量になる。
- 邪念を捨て、友情へ目覚めることで優勝する話には変更しない。大山という世界級の才能が、従来届かなかった全国優勝を現実にする。
- 野球の細部の再現自体は主題ではないが、高校野球としての土台は保つ。大山の最速は155km/h。160km超へ戻さない。
- 神条美空は極めて華やかな美貌と色気を持つが、男を意図的に翻弄しない。本人の人見知り、無関心、生活上の都合が、周囲には別の意味に映る。
- 美空は最後まで野球に詳しくならない。指導は父・厳の言葉と分析が基礎。就任当初のおどおどした模倣が、物語開始時には監督らしい口調として身についている。
- 父娘の「全国優勝すれば監督を辞め、一生実家で暮らしてよい」という取り決めは、優勝エンドまで平野にもプレイヤーにも明かさない。
- 結婚の噂はチーム内限定。入学前から全員が知って入る設定にしない。入部後に惚れる者も、中学時代の観戦で一目惚れした者もいる。
- 大山は中学時代に美空へ一目惚れし、自分の意思で結婚を望んでいる。噂が結婚願望を生んだ人物ではない。
- 新庄は部内の結婚の噂を知らず、美空を恋愛相手として意識する。リンクスの社長の息子である。
- 日和への感謝や信頼は本物。毎回傷つく失恋役にはしない。
- 大山と平野は普段から対等。大山は平野を野球の競争相手とは見ないが、美空との距離には強く嫉妬する。平野は大山の野球を尊敬し、人としては冷めた目も向ける。この関係を解説する台詞は不要。

## 冒頭時点の平野

- 平野知樹は他県から入学した、普通に野球が好きな少年。最初からスコアラー志望ではない。
- 選手として甲子園優勝を目指して入部する。美空を見れば美貌に目を奪われるが、恋愛で野球の目的が変わる人物ではない。
- 後に、鳳翔の同期や先輩の異常な実力と熱量に囲まれ、競争する意欲が早々に自然消滅し、記録を頼まれる役割が定着する。重大な挫折や退部の危機として描かない。
- 普通の強豪校なら選手として意欲を持ち続けたはず、という下地を守る。最初から臆病、怠惰、無気力にしない。
- 平野の内心で毎回笑いを解説しない。表情や沈黙で伝えられる部分を長いツッコミへ置き換えない。
